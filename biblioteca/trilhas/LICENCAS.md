# Licencas das trilhas

Toda faixa usada num video precisa de uma linha aqui. A licenca de cada arquivo
fica registrada (brief 6.2) — sem isso, uma reivindicacao de direitos no YouTube
vira uma investigacao arqueologica.

| Arquivo | Origem | Licenca | Atribuicao exigida | Data |
|---|---|---|---|---|
| _(vazio)_ | | | | |

## O que pode entrar

- **Gerada para o canal.** Biblioteca propria, produzida uma unica vez: abertura,
  tensao, batalha, descoberta, fechamento. Registrar o provedor e a data.
- **Biblioteca livre.** Creative Commons ou dominio publico. Registrar a URL da
  licenca, nao so o nome dela.

## O que nao pode

Faixa de origem incerta, "achei no YouTube", ou licenca que exige atribuicao sem
que a atribuicao caiba na descricao do video.
